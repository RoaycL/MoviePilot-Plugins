# MoviePilot-Plugins

个人维护的 [MoviePilot](https://github.com/jxxghp/MoviePilot) 第三方插件仓库。

## 📦 插件列表

| 插件名称 | 插件标识 | 当前版本 | 兼容性 | 简介 |
| :--- | :--- | :--- | :--- | :--- |
| **飞牛论坛签到** | `fnossign` | `2.5.7` | V2 / V3 | 自动完成飞牛私有云论坛（fnOS）每日打卡签到，支持积分统计、失败重试与历史记录展示 |
| **癫影自动签到** | `Dian115Sign` | `1.0.3` | V2 / V3 | 支持普通签 / 运气签、连续签到与积分统计、结果通知和失败重试 |

插件名称、版本与兼容性以仓库清单 [package.json](package.json)、[package.v2.json](package.v2.json) 和 [package.v3.json](package.v3.json) 为准。更新插件时请同时更新对应清单和本表。

---

## 🚀 安装方法

1. 打开 MoviePilot Web 管理面板。
2. 进入 **设定** -> **插件** -> **第三方插件仓库**。
3. 添加本仓库地址：
   ```text
   https://github.com/RoaycL/MoviePilot-Plugins
   ```
4. 进入 **插件市场**，搜索 **飞牛论坛签到** 或 **癫影自动签到** 并安装所需插件。
5. 在插件配置页填写对应站点的账号凭据，保存后开启定时任务；首次使用建议手动运行一次，并检查插件日志和通知结果。

## 🛠️ 飞牛论坛签到功能特性

- 每日自动打卡，获取飞牛币与签到奖励
- 记录连续签到天数、积分、牛值等数据
- 支持失败自动重试机制与重试延迟
- 支持通过 MoviePilot 统一通知通道（Telegram/微信等）发送签到报告
- 遇到阿里云 ESA 普通 JS 验证时自动调用无头浏览器计算；若遇人工滑块安全暂停并通知，避免误判或反复请求

## 🛠️ 癫影自动签到功能特性

- 支持普通签到与运气签到模式切换
- 统计连续签到、积分与签到记录
- 支持通知和失败重试
- `1.0.3` 修复首次安装尚未保存配置时读取 `_enabled` 导致的异常
